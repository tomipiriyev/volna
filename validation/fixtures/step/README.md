# STEP fixtures

All files here are generated by `generate_fixtures.py`, using FreeCAD 1.1 run
headless:

```bash
/Applications/FreeCAD.app/Contents/Resources/bin/freecadcmd validation/fixtures/step/generate_fixtures.py
```

FreeCAD's headless export drops colors, so the script adds AP214
`STYLED_ITEM` / `COLOUR_RGB` entities afterwards. The inch fixture is written
with inch coordinates and a `CONVERSION_BASED_UNIT('INCH')` length unit.
Dimensions below are in mm.

| File | Contents | Exercised by |
|---|---|---|
| `dipole.step` | Two r = 1 cylinders, 29 long, 1 mm gap at the origin (≈ 2.4 GHz half-wave). Copper color. | Import, names/colors, whole-face picking, 1 mm feed gap, M3 STEP-vs-programmatic check |
| `dipole_inch.step` | The same dipole, declared in inches | Unit detection (`inch`), mm conversion, unit override |
| `monopole_ground.step` | r = 1, h = 29 monopole 1 mm above a 125 × 125 × 1 ground plate | Feed direction and sign, shorted-gap detection, M2/M3 monopole benchmark |
| `patch_fr4.step` | openEMS *Simple Patch Antenna* geometry: 60 × 60 × 1.524 substrate, 32 × 40 patch and 60 × 60 ground as 35 µm copper solids | Thin conductor plates → sheets, thin dielectric → refined slab, 1.524 mm feed gap at x = −6, M3 dielectric benchmark |
| `patch_sheets.step` | The same patch with zero-thickness patch and ground faces | Zero-thickness sheet detection; sheets rejected as dielectrics |
| `assembly_nested.step` | `antenna_assembly` → rotated `pcb` sub-assembly (substrate, trace), a hollow radome, two linked standoffs | Hierarchy, baked instance transforms, unique body ids, thin-wall detection |
| `open_shell.step` | A box with its top face removed | Open-surface diagnostic |
| `overlap_dielectrics.step` | Two overlapping blocks | Overlap / priority diagnostic |
| `thin_features.step` | A 35 µm plate tilted 30° about x, and an r = 0.1 wire along x | Unsupported oblique thin feature; thin-wire classification |

Generation notes:
- FreeCAD wraps multiple top-level objects in an assembly named after the
  document. Document names are prefixed `fx_` so they never collide with part
  names.
- `freecadcmd` can evaluate the script more than once per run, so a guard
  keeps generation to one pass.
